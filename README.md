# Digital-Controller-for-3-Phase-Inverter-on-Zynq-7000
The C code implements the control software for a grid-connected 3-phase converter on a Xilinx Zynq SoC. The system regulates currents and voltages in real time and synchronizes with the power grid using a PLL (SOGI). Further the system utilizes the communication with the Zynq FPGA via BUS and with a GUI.
